# SentinelBank

## Project idea

A secure-banking lab: a SQL Server database that protects itself, defenses against
SQL injection and man-in-the-middle attacks, fraud detection on the PaySim dataset,
a Dash and Plotly monitoring dashboard, and automation with an AI agent that only
proposes actions and waits for human approval.
